# Little's Law — Interactive Simulator

> **WIP = Throughput × Cycle Time**

An interactive simulator that makes Little's Law tangible for coaching sessions, workshops, and executive conversations.

## Features

- **Real-time animated pipeline** — items flow through the system, aging from green to red
- **Native time units** — input directly in days, weeks, or months (no mental conversion)
- **Equivalence display** — see the same throughput/cycle time in all other units
- **Bilingual** — full French/English toggle
- **Coaching insights** — contextual diagnostic messages based on WIP/Throughput ratio
- **Coaching reference panel** — explains why Little's Law matters in practice

## Quick Start

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Import this repo in [vercel.com/new](https://vercel.com/new)
2. Framework preset: **Vite**
3. Deploy — done

No build settings to configure. Vercel auto-detects Vite.

## Stack

- React 18
- Vite 6
- Zero dependencies beyond React
